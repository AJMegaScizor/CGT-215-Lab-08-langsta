# CGT-215-Lab-08-langsta
A game where the user is able to shoot ducks to gain points using 5 arrows.

The ducks spawn in an interval 500 ms coming from the left side of the screen and automatically being removed on the right end.
Every time an arrow is shot upwards with the 'spacebar' from the crossbow it removes 1 count from the number of available arrows displaye din the bottom left corner.
If an arrow hits the top of the screen it is removed from the gameworld and if it hits a duck it is also removed from the gameworld AND the player gains 10 points which is displayed in the bottom right corner.
After all 5 arrows are used up the game displays a "Game Over screen" with the last frame displayed pressing 'spacebar' again closes the program.
